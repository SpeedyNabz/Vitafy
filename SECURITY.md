# Private data and issue reports

Do not post passwords, access/refresh tokens, `credentials.json`, account-cache
directories, raw `vam.log`, or unredacted screenshots of account details.
The main Vita data directory remains `ux0:data/VitaSpot/`.

For a bug report, provide the version, device model, relevant firmware/plugins if
you choose to share them, steps, observed sound/UI behavior, and minimal numeric
error codes. Redact usernames, device/network identifiers and track/account data
when they are unnecessary. Build success and actual playback are different facts.

Use GitHub's private vulnerability reporting if enabled for sensitive security
issues. Otherwise avoid public disclosure of account information and ask the
maintainer for an appropriate private channel. No dedicated security response
service or response-time guarantee is established.
