# Vitafy 0.1.0

Released 15 November 2026. The user confirmed that the preview.7 Home build
works as intended and approved promoting it to a release. **0.1.0 uses that exact
VPK unchanged**: APP_VER 01.29, Home ATTRIBUTE=32776, title ID `VTAM00001`.
The source-lock build identifier remains `0.1.0-preview.7` for provenance.

## Included

- Native Spotify playback with Home-screen continuation, desktop-inspired sidebar,
  Home shelves, playlist folders, search, queue and album/artist navigation.
- Complete playlist loading, Spotify-style sorting dropdowns, stacked category/By
  you library filters, persistent pins and shared song/playlist hearts.
- Lossless-first Best quality, Medium/Low options, configurable screen dim/off
  timers defaulting to Never and a full-screen touch/controller keyboard.
- Account-scoped persistent browse metadata, reusable playlist snapshots, bounded
  LRU caches, stale-data revalidation and 16/32 MiB browse-cache controls.
- Sorted playback for up to 10,000 playable tracks, preserving duplicate positions,
  with cancellable chunk preparation and explicit original-order fallback.
- Guarded playlist/queue edits and resource/loading diagnostics.

See the [preview.7 implementation report](preview7.md) for exact bounds and
[desktop UI audit](../desktop-ui-audit.md) for service limitations.

## Install or update

Download **Vitafy-0.1.0.vpk** and verify it against **SHA256SUMS.txt**. Exit the
running player through Settings before updating with your normal Vita package
installer. The title and `ux0:data/VitaSpot/` path are preserved; uninstalling or
clearing saved data is not required. Spotify Premium and compatible unofficial
service protocols are required. No offline-download capability is claimed.

## Verification

The release includes the unchanged, user-accepted Home binary. Automated checks
passed: 28 real Rust tests, nine desktop CTest cases, five offline UI suites,
fresh native linking/package checks, and source/hash verification. Debug ELF/VELF

## Known limits

The general device acceptance report is not a measured cache benchmark, 10,000-song
hardware stress test or a guarantee for every Spotify account/service condition.
Long audio soak, remote handoff, low-storage recovery and true sleep require
separate evidence. Do not launch a game while Vitafy is active: a game-triggered
forced-close transition previously hung the shell. Use Settings > Exit first.

Vitafy is unofficial and is not affiliated with Spotify or Sony. Upstream frontend
and asset redistribution terms remain unresolved; this release does not establish
a blanket license for the application. Existing component/font notices are retained;
see [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).
