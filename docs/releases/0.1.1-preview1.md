# 0.1.1-preview.1 - Bluetooth volume and Next buffering

Home test package **01.31**, ATTRIBUTE=32776, title ID `VTAM00001`.
Existing data/sign-in is preserved. Exit the player before updating.

- The app/Spotify slider controls app gain. Vita/headset buttons retain independent
  hardware-volume control; the app stops polling and writing generic system volume.
- Next-song preparation starts earlier with buffered headroom, reuses one preload
  slot, follows queue changes and retains the selected audio quality.
- Superseded async loaders are cancelled; async load phases have a 45-second
  deadline. Blocking IO is not covered by that wall-clock guarantee.
- Speculative failures retain the next queue entry. Old playback events cannot
  overwrite a newer skip. Mute now reconciles correctly.

32 Rust tests, nine desktop CTest cases and five offline UI suites pass. Native
package checks are recorded separately. Actual Bluetooth behavior and audible
skip latency need user testing; no performance improvement is claimed as measured.
The published 0.1.0 release is unchanged.
